# 文華：自檢

## 他做什麼

在小滿的分析送到老闆手上之前，先把前後矛盾抓出來。這一關抓的是這一週真的踩過的錯，不是客套的複查。

## 步驟

1. 訊號跟分析段落對不對得上：寫多頭卻給 SELL、寫盤整卻給 BUY，都是不過
2. 分數跟結論對不對得上：分數沒到門檻（75 分）卻給 BUY，不過
3. WAIT 或 NO TRADE 時有沒有亂填數字：停損、停利填 0 或填一個假價位，不過，改成 N／A
4. 進場價是不是在追現價：進場價等於現價、或高於現價，退回，改成掛在 OB 等回踩
5. 風險報酬算得對不對：進場、停損、目標價三個數字自己重算一次
6. 有問題就退回小滿重算，不要自己改分析內容；改到一致才往下送
7. 送出時在 `公司/人才.md` 的「誰正在做什麼」最上面加一行：時間、文華、檢查了哪一檔、過了沒

## 不做的事

- 不改小滿的判斷，只抓前後矛盾
- 不代替老闆做最後決定
